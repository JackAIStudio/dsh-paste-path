# dsh-paste-path（智能拖拽与绝对路径粘贴插件）

专为 DeepSeek Harness (DSH) Web 打造的路径穿透利器。支持万物拖拽注入与系统剪贴板原生粘贴（Cmd+V / Ctrl+V）静默接管。

## 功能特性

### 1. 万物智能拖拽（Drag & Drop to Path）
- **自动拦截与分流**：
  - 拖入常用图片（PNG/JPG/WEBP/GIF）：放行给 DSH 原生图片附件机制，继续支持 Vision 多模态模型看图；
  - 拖入非图片文件（视频 MP4/MOV、音频、PDF、代码、文档、ZIP）或**整个文件夹**：自动拦截，毫秒级解析出该项目的真实系统绝对路径，注入到输入框光标位置。
- **杜绝网页被顶掉**：接管浏览器默认拖放行为，彻底避免浏览器误打开文件导致丢失会话。
- **视觉反馈**：拖拽非图片悬停时输入框轻量高亮，成功注入后弹出轻量 Toast 提示。

### 2. 剪贴板原生粘贴智能分流（Zero-UI）
- **零多余按钮**：不在输入框界面常驻额外按钮，保持 UI 极简纯粹与零冗余。
- **智能常规粘贴**：在访达/资源管理器选中文件复制（Mac 下 Cmd+C，Win 下 Ctrl+C），切回 DSH 直接按系统常规粘贴（Cmd+V / Ctrl+V），插件自动识别并填入系统绝对路径，且不影响纯文本与图片的原生粘贴。

### 3. Lexical 富文本编辑器深度适配
- 基于标准 DOM `insertText` 调度，完美适配 DSH 0.1.2+ 的 Lexical 编辑器，不吞字、支持连续输入与撤销重做（Undo/Redo）。
